# 🎓 StudyMate – Student Study Planner

A modern, responsive student study planner built to help students organize their academic schedules, manage subjects, track assignments, and monitor study progress.

## 🚀 Live Application

**Try StudyMate here:**

https://mellifluous-concha-bacb8e.netlify.app/

StudyMate is also installable on Android as a Progressive Web App (PWA).

## ✨ Features

- 📚 Subject Management
- 📝 Tasks and Assignment Tracking
- 📅 Study Timetable
- 📊 Academic Progress Tracker
- ⏱️ Pomodoro Timer
- 🎯 Daily Study Goals
- 🌙 Theme Customization
- 📱 Responsive User Interface
- 📲 Installable PWA Support

## 🛠️ Technology Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- Lucide React
- Progressive Web App (PWA)
- Netlify

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/Op-Vedant-2007/study-mate-student-planner.git
```

Navigate to the project folder:

```bash
cd study-mate-student-planner
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🏗️ Production Build

To create a production build:

```bash
npm run build
```

## 🌐 Deployment

The application is deployed using Netlify.
